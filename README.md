✦ Grimoire 使用指南 · 致新守护者
欢迎来到你的魔典。这不是一个普通的 App，而是一本会随你呼吸生长的数字手账。所有数据只储存在你的手机本地，不上传云端，不联网，不注册——你的秘密只属于你。
一、如何将它安放在桌面（推荐）
iPhone / iPad：用 Safari 打开链接 → 点击底部分享按钮 →「添加到主屏幕」。此后它将以全屏模式运行，像一本真正的魔典静候于桌面。
Android：用 Chrome 打开 → 右上角菜单 →「添加到主屏幕」。
首次打开后，建议去「我的」→「魔典归属」为它冠名，首页标题将变为「你的名字's Grimoire」。
二、六大密室导航
01 首页 · 今日观测
时钟与日期之下，每日会随机浮现一句书摘、电影台词或古诗词（中英双语）。七宫格快捷入口可一键跳转到常用模块。下方的「今日观测」实时汇总你的待办、饮水、体重与运动数据。AI 天使会根据这些数据，生成当日规划建议——它不是联网 AI，而是本地规则引擎，冷静、不煽情、只给动作。
02 塔罗 · 七十八张低语
78 张牌全库齐备。点击任意牌可 3D 翻转查看正逆位含义，保存日运时可附加关键词与个人解读，日运支持无限追加日记，形成一条时间线。牌阵问事支持单张指引、圣三角、二选一与自定义牌阵，按抽牌顺序记录，可逐张查看含义、粘贴 Kimi 解读，并追加实际验证反馈。
03 档案 · 不可见之物的卷宗
塔罗日运：瀑布流展示历史日运，点击可追加日记。
大众占卜：记录你在 B 站/YouTube 观看的大众占卜，留存所选组别、UP 主解读与复盘链接，方便日后对照。
占卜区：含塔罗牌阵、雷诺曼、六爻、梅花易数、奇门遁甲、小六壬六类独立记录，均支持 Kimi 解读与事后验证回填。
命盘：八字、紫微斗数、西方星盘、印度占星四套命盘的归档处，粘贴排盘结果与 Kimi 分析即可。
04 提升 · 成为自己的手艺
升学看板：钉上目标院校后，可记录项目、截止日期与申请状态（待开始→录取）。支持勾选雅思/托福/GRE/GMAT 等要求，填写「目标分数」与「现有成绩」，卡片上直接显示 DDL 倒计时。也可添加自定义要求。
学习 ToDo：按学习/升学/生活/创作分类，支持 AI 点评待办清单。
理财学习：知识库带进度条，投资记录区分买入/卖出，收支台账自动统计月度结余。
饮食健康：体重 14 天曲线图、饮食热量圆环、饮水打卡与补剂记录、经期记录（含疼痛等级）。
运动：记录类型/时长/心情，自动统计本周累计。
阅读观影：支持书摘/台词中英双语摘录、评分与 Kimi 分析。
05 灵修 · 显化与庇护所
显化日记：每日感恩 ×3、核心目标（必须用现在时态书写）、情绪标签、宇宙 Signs、明日行动承诺。AI 天使会检查语法与聚焦度。
树洞：只进不出，仅你可见。投放心事，AI 天使按情绪标签给予安抚。
神谕卡：每日一抽，16 张内置牌卡，封存启示。
梦境档案：记录梦境场景、类型与情绪，AI 以弗洛伊德（潜意识视角）+ 周公解梦（预兆视角）双维度解析。另设清醒梦 / Shifting 训练记录，支持记录训练方法、清醒度自评（0-10）与周统计。
06 我的 · 圣所
魔典冠名、数据导出（JSON 备份）、导入恢复、清空重置。请务必定期导出备份，换设备时通过导入即可恢复全部记忆。
三、重要规则
数据完全本地：所有记录存在你手机的浏览器本地存储中。清除浏览器数据或卸载图标会导致丢失，定期导出 JSON 备份是唯一的保险。
分享链接不会泄露隐私：你把链接发给朋友，每个人打开都是一本空白魔典，数据互不干扰。
离线可用：除 Google Fonts 字体加载外，核心功能无需网络。
